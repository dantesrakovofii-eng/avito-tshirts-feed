# Авито: GitHub Pages XML-фид

## Что делает проект

- Подготавливает XML по структуре пользовательского шаблона «Мужская одежда — Кофты и футболки» от 21.10.2026.
- Берёт только строки `Status=Одобрено`, у которых `DateBegin` наступила.
- Ограничивает количество **новых одобренных** карточек четырьмя на дату.
- Сохраняет в фиде ранее одобренные карточки с постоянными `Id` (не только сегодняшние).
- При незаполненных данных или отсутствии пригодных объявлений **не публикует пустой XML**.
- GitHub Actions собирает и публикует XML в GitHub Pages по расписанию и после изменений каталога.

## Важно

**Сейчас все 28 карточек — черновики, публикация не начнётся сама.** Нужны реальные фото, цена, наличие, адрес и допустимые для этой категории значения полей. Генератор проверяет техническое заполнение, а не гарантирует прохождение валидации Авито.

Программа не генерирует изображения футболок и сама не придумывает товары. Не отмечайте карточку одобренной, пока изображение и описание не готовы и не подтверждены. Авито может трактовать похожие предложения как дубли.

## Установка

1. Создайте **публичный** GitHub-репозиторий `avito-tshirts-feed`. Загрузите **содержимое этой папки** на ветку `main` с сохранением `.github/workflows/pages.yml`.
2. GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. В `catalog.csv` заполните реальными данными выбранные товары. В `ImageURLs` используйте абсолютные прямые HTTPS-ссылки на изображения, разделяя несколько ссылок `|`.
4. `Status` измените на `Одобрено` только после проверки карточки. Для немедленного теста поставьте `DateBegin` = сегодняшняя дата в формате YYYY-MM-DD.
5. Откройте **Actions → Build and publish Avito feed → Run workflow**. Если все карточки — черновики, запуск завершится ошибкой **намеренно**.
6. После успешного запуска ссылка будет `https://ВАШ-ЛОГИН.github.io/avito-tshirts-feed/catalog.xml`. Проверьте, что она открывает XML, а затем вставьте её в Авито: **Автозагрузка → Настройки → Перейти на загрузку по ссылке**.
7. Сначала протестируйте одну подтверждённую карточку и проверьте отчёт Авито. Только затем одобряйте новые товары.

> GitHub Pages и репозиторий с каталогом являются публичными: **не** загружайте клиентские данные, телефоны или внутренние цены. Авито контактный телефон берите только из разрешённых и публичных данных магазина. Не храните токены и ключи в репозитории.

## Файлы

- `catalog.csv` — 28 карточек-заготовок
- `generate_feed.py` — проверка и построение XML
- `.github/workflows/pages.yml` — автозапуск (07:00 UTC ежедневно, плюс после изменения каталога)

## Что понадобится для настоящего автоматического создания 4 новых товаров каждый день

Отдельный генератор макетов, размещение готовых изображений по HTTPS, согласование цены и ассортимента, правила одобрения и добавление одобренных строк в `catalog.csv`. В этом стартовом пакете автоматизированы **выгрузка и публикация утверждённого каталога**, а не само производство дизайнерских макетов.
